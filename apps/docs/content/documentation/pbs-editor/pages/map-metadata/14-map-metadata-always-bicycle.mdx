## Always Bicycle

<InputToggle label="Always Bicycle:"/>
This toggle determines wether the bicylce will be automatically mounted upon the Player entering the **map**.
<br/>
- On - The Player's bicycle <Gr>will automatically</Gr> be mounted.
- Off - The Player's bicycle <Rd>will not automatically</Rd> be mounted. 
<br/>
---

### Default Value 

The <Or>Always Bicylce</Or> field is <Yl>optional</Yl>, but no default value is assigned by the editor.
<br/>
If left undefined, the player's bicylce will not be automatically mounted upon entering the **map**.
