## File Selection

<InputSelect
  label="Current Map Metadata PBS File:"
  width={250}
  initValue="map_metadata.txt"
  placeholder="Select File"
  options={["map_metadata.txt"]
    .map(file => ({ label: file, value: file }))
  }
/>

This dropdown allows you to choose between all available <Gr>Map Metadata PBS files</Gr> detected in your project.
<br/>
The primary file is typically named `map_metadata.txt`, but the editor also supports additional files following the format `map_metadata_xxx.txt`.
<br/>
The <Yl>underscore (_)</Yl> is required for these extra files to be recognized. Any text can follow it (e.g. map_metadata_custom.txt), but files without this naming pattern will <Rd>not be detected</Rd> as **Map Metadata PBS files**.
<br/>
If only a single file is available, the dropdown will be automatically <Gr>disabled</Gr>, and that file will be selected by default.
