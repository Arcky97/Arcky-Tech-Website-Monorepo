## Bicycle

<InputToggle label="Bicycle:"/>
This toggle determines wether player can use their Bicycle on this **map**.
<br/>
- On - The Player <Gr>can toggle</Gr> their bicycle on the **Map**.
- Off - The Player <Rd>cannot toggle</Rd> their bicylce on the **Map**. 
<br/>
---

### Default Value 

The <Or>Bicylce</Or> field is <Yl>optional</Yl>, but no default value is assigned by the editor.
<br/>
If left undefined, the player will only be able to toggle it's bicycle if the **Map** is an outdoor map.
