## Name

<InputText label="Name:" value="Intro" width={25}/>

The <Or>Name</Or> defines the <Gr>Name</Gr> of the **Game Map** as shown to the player in-game. 
<br/>
This is the label used in the pause menu, save screen, load screen, show area feature, making it an important part of how the **Map** is presented to the player.
<br/>
---

### Default Value 

The <Or>Name</Or> field is <Yl>Required</Yl> and must be defined for every single <Gr>Game Map</Gr>. 
<br/>
If left undefined, the RPG Maker map's name will be used instead.
