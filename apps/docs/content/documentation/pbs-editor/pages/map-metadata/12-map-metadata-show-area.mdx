## Show Area

<InputToggle label="Show Area:"/>
This toggle determines wether a location signpost is being displayed at the top left of the screen when entering the **Map**.
<br/>
- On - <Gr>A location signpost</Gr> will appear for the **Map**.
- Off - <Rd>No location signpost</Rd> will appear for the **Map**. 
<br/>
---

## Default Value 

The <Or>Show Area</Or> field is <Yl>optional</Yl>, but no default value is assinged by the editor.
<br/>
If left undefined, the **Map** will have no location signpost shown.
