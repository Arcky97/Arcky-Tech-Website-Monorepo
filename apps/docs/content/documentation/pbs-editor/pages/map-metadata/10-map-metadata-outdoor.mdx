## Outdoor

<InputToggle label="Outdoor:"/>
This toggle determines wether the **Map** is an outdoor map.
<br/>
- On - The **Map** will be <Gr>an outdoor map</Gr>.
- Off - The **Map** wil be <Gr>an indoor map</Gr>. 
<br/>
---

### Default Value 

The <Or>Outdoor</Or> field is <Yl>optional</Yl>, but no default value is assigned by the editor.
<br/>
If left undefined, the **Map's** will be set as an indoor map.
