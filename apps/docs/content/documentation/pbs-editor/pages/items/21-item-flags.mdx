## Flags

<InputMultiSelect
  label="Flags"
  maxWith={275}
  initValue={["Repel", "Fling_30"]}
  placeholder="Select Flags"
  options={["Mail", "IconMail", "PokeBall", "SnagBall"]
    .map(option => ({ label: option, value: option }))
  }
/>
The <Or>Flags</Or> field is a <Gr>multi-select dropdown</Gr>, allowing you to assign multiple values to an **Item** at the same time.
<br/>
All selected <Or>Flags</Or> are stored in the PBS file as a <Yl>comma-separated list</Yl>, ensuring compatibility with the underlying data format.
<br/>
The available options in this dropdown can be managed through the <Gr>Item Editor Settings</Gr>. 
<br/>
---

### Default Value 

<Or>Flags</Or> do not have a default value.
<br/>
---

### Options 

By default, the editor includes the following <Or>Flags</Or>:
- Mail - The **Item** is a Mail Item.
- IconMail - The **Item** is a Mail Item, and the images of the holder and two other party Pokémon appear on the Mail.
- PokeBall - The **Item** is a Poké Ball item.
- SnagBall - The **Item** is a Snag Ball (i.e. it can capture enemy trainers' Shadow Pokémon).
- Berry - The **Item** is a berry that can be planted.
- KeyItem - The **Item** is a Key Item.
- EvolutionStone - The **Item** is an evolution stone.
- Fossil - The **Item** is a fossil that can be revived. Not to be used for the incomplete fossils from Gen 8 which are pieced together to revive a Pokémon.
- Apricorn - The **Item** is an Apricorn that can be converted into a Poké Ball.
- TypeGem - The **Item** is an elemental power-raising Gem.
- Mulch - The **Item** is mulch that can be spread on berry patches.
- MegaStone - The **Item** is a Mega Stone. This does NOT include the Red/Blue Orbs.
- MegaRing - The **Item** is a Mega Ring, which allows Mega Evolution.
- Repel - The **Item** is a Repel, and can be used automatically when a Repel runs out.
- Fling_30 - The **Item** can be thrown by the move Fling. The number is Fling's base power when used with the **Item**. The number can be any number, but should be greater than 0. <Gr>The Editor provides extra options for Fling from `Fling_5` up to `Fling_100` in steps of 5</Gr>.
- NaturalGift_POISON_80 - The **Item** can be used by the move Natural Gift. The type and number are Natural Gift's type and base power when used with the **Item**. The type can be any type, and the number can be any number but should be greater than 0. <Gr>The editor provides extra options for NaturalGift for each Type and in steps of 5.</Gr>
<br/>
Additional <Or>Flags</Or> can be <Gr>added or removed</Gr> via the <Yl>Item Flags</Yl> section in the Settings menu, allowing full customization of available <Or>Flag</Or> options. <Rd>The `Fling` and `Natural Gift` <Or>Flags</Or> cannot be removed as these are auto generated by the Editor</Rd>.
