## Show Quantity

<InputToggle label="Show Quantity"/>
This toggle detemines wether the **Item** show its quantity in the Bag.
<br/>
Only used to show the quantity of a Key Item, TM or HM.
- On — The **Item** will <Gr>show its quantity</Gr> in the Bag.
- Off — The **Item** will <Gr>not show its quantity</Gr> in the Bag.
<br/>
---

### Default Value 

The <Or>Qauntity</Or> field is <Yl>Optional</Yl>, but no default value is assigned by the editor.
<br/>
If left undefined, the **Item's** <Or>Show Quantity</Or> value will be
- On if the **Item** is a Key Item TM or HM.
- Off if the **Item** is anything else.
