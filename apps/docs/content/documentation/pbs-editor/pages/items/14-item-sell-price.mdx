## Sell Price

<InputNumber label="Sell Price:" value="205" width={7}/>

The <Or>Sell Price</Or> defines <Gr>the amount of money gained </Gr> for the **Item** when selling it to a Poké Mart.
<br/>
---

### Default Value

The <Or>Sell Price</Or> field is <Yl>Optional</Yl>, but no default value is assigned by the editor.
<br/>
If left undefined, the **Item's** <Or>Sell Price</Or> will be <Rd>half the **<Rd>Item's</Rd>** price</Rd>.
