## Sell Coin Price

<InputNumber label="Sell Coin Price:" value="125" width={7}/>

The <Or>Sell Coin Price</Or> defines <Gr>the amount of Coins gained</Gr> for the **Item** when selling it to a Coins Shop.
<br/>
Like mentioned above, only when you have [Arcky's Poke Market Plugin](/poke-market) installed, you can sell items for Coins.
<br/>
---

### Default Value 

The <Or>Sell Coin Price</Or> field is <Yl>Optional</Yl> and will also only appear if you have enabled "Arcky's Poke market" Setting in the Editor. No default value is assigned by the editor.
<br/>
If left undefined, the **Item's** <Or>Sell Coin Price</Or> will be <Rd>half of the **<Rd>Item's</Rd>** Coin Price</Rd>.
