## Pocket

<InputNumber label="Pocket:" value="1" width={7}/>

The <Or>Pocket</Or> defines the <Gr>Bag Pocket Number</Gr> the **Item** is stored in.
<br/>
---

### Default Value 

The <Or>Pocket</Or> field is <Yl>Optional</Yl>, but no default value is assigned by the editor.
<br/>
If left undefined, the **Item's** <Or>Pocket</Or> will be <Rd>1</Rd>. 
<br/>
---

### Options 

By default, this is one of:

- 1 - Items 
- 2 - Medicine
- 3 - Poké Balls 
- 4 - TMs & HMs
- 5 - Berries 
- 6 - Mail 
- 7 - Battle Items 
- 8 - Key Items

The list of <Or>Bag Pockets</Or> is in the script section Settings.
