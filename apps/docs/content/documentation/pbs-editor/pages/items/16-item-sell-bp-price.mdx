## Sell BP Price

<InputNumber label="Sell BP Price:" value="7" width={7}/>

The <Or>Sell BP Price</Or> defines <Gr>the amount of BP gained</Gr> for the **Item** when selling it to a Battle Point Shop.
<br/>
Like mentioned above, only when you have [Arcky's Poke Market Plugin](/poke-market) installed, you can sell items for Battle Points.
<br/>
---

### Default Value 

The <Or>Sell BP Price</Or> field is <Yl>Optional</Yl> and will also only appear if you have enabled "Arcky's Poke market" Setting in the Editor. No default value is assigned by the editor.
<br/>
If left undefined, the **Item's** <Or>Sell BP Price</Or> will be <Rd>half of the **<Rd>Item's</Rd>** BP Price</Rd>.
