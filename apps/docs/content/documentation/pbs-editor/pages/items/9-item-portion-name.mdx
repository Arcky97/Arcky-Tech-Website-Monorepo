## Portion Name

<InputText label="Portion Name:" value="bottle"/>

The <Or>Portion Name</Or> defines the <Gr>name of the portion</Gr> of the **Item**, used in most in-game messages.
<br/>
When the player has found an item, instead of "The player found 1 Repel", it could say "The player found 1 bottle of Repel". 
<br/>
---

### Default Value 

<Or>Portion Name</Or> does not have a default value.
