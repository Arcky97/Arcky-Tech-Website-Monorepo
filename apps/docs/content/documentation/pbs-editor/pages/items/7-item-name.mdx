## Name

<InputText label="Name:" value="Repel" width={25}/>

The <Or>Name</Or> defines the <Gr>singular name</Gr> of the **Item** as shown to the player in-game.
<br/>
This is the label used in menus, summaries, and battle interfaces, making it an important part of how the **Item** is presented to the player.
<br/>
---

### Default Value

The <Or>Name</Or> field is <Yl>optional</Yl>, but no default value is assigned by the editor.
<br/>
If left undefined, the **Item's** <Or>Name</Or> will be <Rd>Unnamed</Rd>.
