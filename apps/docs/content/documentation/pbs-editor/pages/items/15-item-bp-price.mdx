## BP Price

<InputNumber label="BP Price:" value="15" width={7}/>

The <Or>BP Price</Or> defines the <Gr>Cost</Gr> of the **Item** when the player buys it from a Battle Point Shop.
<br/>By default, the player cannot sell items for BP. But you can if you have [Arcky's Poke Market Plugin](/poke-market) installed.
<br/>
---

### Default Value 

The <Or>BP Price</Or> field is <Yl>Optional</Yl>, but no default value is assigned by the editor.
<br/>
If left undefined, the **Item's** <Or>BP Price</Or> will be <Rd>1</Rd>.
