## Coin Price

<InputNumber label="Coin Price:" value="250" width={7}/>

The <Or>Coin Price</Or> defines the <Gr>Cost</Gr> of the **Item** when the player buys it from a Coin shop.
<br/>By default, there's no Coin Price parameter. But there is if you have [Arcky's Poke Market Plugin](/poke-market) installed.
<br/>
---

### Default Value 

The <Or>Coin Price</Or> field is <Yl>Optional</Yl>and will also only appear if you have enabled "Arcky's Poke market" Setting in the Editor. No default value is assigned by the editor.
<br/>
If left undefined, the **Item's** <Or>Coin Price</Or> will be <Rd>1</Rd>.
