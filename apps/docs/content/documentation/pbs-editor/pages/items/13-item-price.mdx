## Price

<InputNumber label="Price:" value="410" width={7}/>

The <Or>Price</Or> defines the <Gr>Cost</Gr> of the **Item** when the player buys it from a Poke Mart.
<br/>
If an **Item** has a <Or>Price</Or> of 0, the player cannot sell it.
<br/>
---

### Default Value 

The <Or>Price</Or> field is <Yl>Optional</Yl>, but no default value is assigned by the editor.
<br/>
If left undefined, the **Item's** <Or>Price</Or> will be <Rd>0</Rd>.
