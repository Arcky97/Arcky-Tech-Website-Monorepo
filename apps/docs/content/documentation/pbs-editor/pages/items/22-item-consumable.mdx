## Consumable

<InputToggle label="Consumable"/>
This toggle determines wether the **Item** will be consumed after use from the Bag.
<br/>
Usually only used to make a **non-Key Item** infinite use (e.g. Black/White Flutes).
- On — The **Item** will <Gr>be consumed</Gr> after use from the Bag.
- Off — The **Item** will <Gr>not be consumed</Gr> after use from the Bag.
<br/>
---

### Default Value

The <Or>Consumable</Or> field is <Yl>Optional</Yl>, but no default value is assigned by the editor.
<br/>
If left undefined, the **Item's** <Or>Consumable</Or> value will be 
- On if the **Item** is a Key Item, TM or HM.
- Off if the **Item** is anything else.
