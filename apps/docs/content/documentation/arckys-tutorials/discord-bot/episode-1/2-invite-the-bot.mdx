## Invite the Bot 

- In the side menu click on "OAuth2" and scroll down to "OAuth2 URL Generator" section.

  <MediaGallery
    items={[
      {
        src: "documentation/arcky-tutorials/discord-bot-tutorial/OAuth2 URL Generator.png",
        width: 879,
        height: 109,
        alt: "OAuth2 URL Generator"
      }
    ]}
    size="full"
  />
- In *Scopes* enable 
  - "bot"
  - "application.commands"

  <MediaGallery
    items={[
      {
        src: "documentation/arcky-tutorials/discord-bot-tutorial/Scopes.png",
        width: 341,
        height: 639,
        alt: "Scopes"
      }
    ]}
    size="full"
  />
- In *Bot Permissions* enable
  - Send Messages
  - Use Slash commands
  - Read Message History

  <MediaGallery
    items={[
      {
        src: "documentation/arcky-tutorials/discord-bot-tutorial/Bot Permissions.png",
        width: 743,
        height: 722,
        alt: "Bot Permissions"
      }
    ]}
    size="full"
  />
- Copy the Generated URL and paste it in your browser to invite your bot to your server.

  <MediaGallery
    items={[
      {
        src: "documentation/arcky-tutorials/discord-bot-tutorial/Generated URL.png",
        width: 880,
        height: 106,
        alt: "Generated URL"
      }
    ]}
    size="large"
  />
- The bot has now joined the server and appears offline in the member list.
