<Header title="NotEnoughMoney">
  How to use and define NotEnoughMoney speeches.
</Header>

The `NotEnoughMoney` determines what the NPC will say when the player does not have enough money to buy an Item.

<PMSpeeches speech="NotEnoughMoney"/>

To define the `Notenoughmoney`, use this structure:

```ruby
NotEnoughMoney: [
  "You don't have enough money."
]
```
